# Taskly 使用指南

[English](USER-GUIDE.md) · **简体中文**

用清单、快速录入和定时提醒管理本地待办。

## 当前可用状态

开发预览，尚未开放付费购买。未来官方桌面版开售时再公布实际交付条款。

## 平台与安装

提供 macOS、Windows、Linux 桌面预览版。按发布附件标注选择系统与 CPU；移动端和手表端尚未交付。

从[官方 Releases](https://github.com/turlamai/taskly/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

## 第一次使用

1. 创建清单，添加一条不含敏感信息的任务；保存前核对解析出的日期。
2. 完成任务，重新打开应用，确认状态已保存。
3. 使用提醒前允许系统通知，在应用运行时测试一次；不要假定退出应用或电脑休眠后仍能送达。

## 数据、备份与恢复

任务使用 SQLite，默认 ~/.taskly/tasks.db，配置在 ~/.taskly/config.ini。退出全部 Taskly 进程后备份整个目录，包含可能存在的 WAL/SHM 文件；先在副本中验证恢复。把正在使用的数据库放进云同步目录，不等于支持多端并发编辑。

## 键盘与编辑

macOS 使用 Command，Windows/Linux 使用 Ctrl：1–4 切换智能视图，N 聚焦快速添加，F 聚焦搜索，Shift+C 切换显示已完成。在任务列表里用方向键移动选择、Enter 打开行内编辑。编辑区始终显示“保存”和“取消”；Enter 保存，Escape 或“取消”丢弃整份草稿，再按一次 Escape 清除选择。日期入口会在原生日历上方提供“今天 / 明天 / 本周末”。选择日期只修改草稿；“保存”、Enter 或点击另一行才会持久化，并显示保存中、成功或错误反馈。显式保存失败时草稿会保留以便重试。删除会暂存约六秒；撤销会恢复相同的任务 ID 与全部元数据。

## 联网、密钥与隐私

核心待办功能在本地运行。更新检查、下载和主动打开的链接会访问外部服务；数据库和诊断文件可能包含任务标题与备注。

## 已知限制

三端提醒均由公共核心一致判定，但 Taskly 必须保持运行，且系统需允许通知投递。桌面发行包尚未附带独立 CLI；源码 CLI 用法见 README。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

DMG、MSI、deb/rpm 与便携压缩包只替换应用文件，不应修改 `~/.taskly/`。更新失败时退出全部 Taskly 进程，用相同安装形态重新安装上一版可信构建；便携版可直接回到上一版程序目录。各安装形态的完整回滚表见下方更新说明。

## 获得帮助

在 [GitHub Issues](https://github.com/turlamai/taskly/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
