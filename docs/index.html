Designed to fade into the background.

Calm colors, thoughtful typography, and nothing you don't need. So you can focus on doing, not managing.

⚡️

Scheduling shortcuts

Add a modifier to any task: "Standup @9am", "Buy milk +1d", "Ship @5pm fri". Taskly extracts the time and leaves the rest as the task. No dials, no calendars.

See the syntax →
🔒

Private by design

Your tasks live in a local SQLite database. No account, no cloud, no tracking.

💻

Truly cross-platform

Native apps for macOS, Windows, and Linux — same clean interface everywhere.

🔄

Sync on your terms

Point Taskly at any cloud-synced folder (iCloud, Dropbox, Syncthing…) and your database follows you across devices. WAL mode keeps concurrent access safe.

Bring your own cloud.
⌘

A CLI that speaks JSON

Taskly ships as a single binary — GUI and CLI in one. Script it, pipe it, hand it to an AI agent. Stable exit codes, structured output, no surprises.

# add a task, get JSON back $ taskly add "Ship v0.4 @friday 5pm" --list "Work" --json $ taskly list --status incomplete --json | jq '.[] | .text'
Single binary. Zero config.
📂

Organized lists

Separate Work, Life, and Ideas into color-coded lists that stay out of each other's way.

Rebuild status

The rebuild is underway.

The v1 native apps are archived. Taskly is being rebuilt on Rivet — one Racket core driving first-party native hosts in WinUI 3, SwiftUI, and GTK4.

✅

M0–M2 · Shipped

The shared Racket core: domain logic and SQLite storage, typed DTOs with generated clients, and in-process RPC.

🔨

M3 · In progress

Windows parity — a C++/WinRT host: the XAML interface carries over, code-behind rewritten in C++.

🍎

M4–M5 · Planned

macOS on a SwiftUI host, then Linux on GTK4.

📦

M6–M7 · Planned

The JSON CLI moves into the Racket core, then release engineering.
